# Gestion de tâches

Application Flask minimale pour la chaîne DevOps du module.

## Démarrage

Dans Git Bash, à la racine du dépôt :

```bash
cp .env.example .env && docker compose up -d --build
```

L'application répond sur http://localhost:8080/health.

La fiche d'une page est dans [docs/fiche.md](docs/fiche.md). Le compte rendu d'incident est dans [docs/incident.md](docs/incident.md).
